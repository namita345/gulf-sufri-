GulfSufra — Interactive Services Section v1

Built on the latest cinematic homepage structure.

Services section behavior:
- Four service cards: Restaurant Websites, Digital Menus, Social Media, Google Business.
- Hover/focus activates a card.
- Sufri switches to the matching reaction pose.
- Sufri speech bubble changes with the active service.
- A persuasive tooltip appears above the hovered card with a CTA.
- Sufri gently floats; he does not travel across the section.
- Responsive layout for tablet/mobile.

Header and hero remain unchanged from the supplied base used for this build.
